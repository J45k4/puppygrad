# Stable Diffusion Reference Fixtures

Small JSON fixtures generated by `scripts/stable_diffusion_reference_fixture.py`
can live in this directory. Large model weights, full latent dumps, and generated
images should stay local-only and must not be committed.

Generate a compact parity fixture when Python Diffusers and model assets are
available:

```bash
scripts/stable_diffusion_reference_fixture.py \
  --model-dir models/stable-diffusion-v1-5 \
  --prompt "hello" \
  --negative-prompt "" \
  --steps 2 \
  --width 512 \
  --height 512 \
  --include-initial-latents \
  --out tests/data/stable_diffusion/hello-ddim.json
```

The fixture captures token ids, attention masks, CLIP embedding slices,
scheduler arrays, first-step UNet predictions, first-step latents, VAE decoded
tensor slices, and RGB tensor statistics. Rust parity tests skip by default when
no JSON fixture or no matching local model directory is available. Set
`PUPPYGRAD_SD_PARITY_FIXTURE=/path/to/fixture.json` to run a local-only fixture
without copying it into this directory. Set
`PUPPYGRAD_SD_PARITY_MODEL_DIR=/path/to/diffusers-model` when the fixture's
`model_source` is not a local path.

Floating-point tensor parity currently uses `5e-2` absolute or relative
tolerance. That is intentionally loose enough for scalar Rust CPU kernels versus
Torch/Diffusers accumulation order while still catching shape/layout mistakes.

Large model weights, generated images, and full-output dumps should stay
local-only. For an end-to-end local backend comparison, run:

```bash
scripts/stable_diffusion_compare_backends.py \
  --puppygrad ./target/debug/puppygrad \
  --model-dir models/stable-diffusion-v1-5 \
  --prompt "hello" \
  --steps 1 \
  --width 512 \
  --height 512 \
  --out-dir /tmp/puppygrad-sd-compare
```
