# Bark Reference Fixtures

Place compact JSON fixtures generated by `scripts/bark_reference_fixture.py` in this
directory. Bark parity tests skip automatically when no fixtures are present.

Tokenizer-only fixtures live under `tests/data/bark/tokenizer/` and are generated
without loading the Bark model weights:

```bash
scripts/bark_tokenizer_fixtures.py \
  --model-dir models/bark-small \
  --output tests/data/bark/tokenizer/reference.json
```

These fixtures cover representative prompts for deterministic text preprocessing:
short English, punctuation, numbers, mixed case, truncation, and
unknown/non-ASCII text.

Prefer deterministic greedy fixtures when possible:

```bash
scripts/bark_reference_fixture.py \
  --model-dir models/bark-small \
  --text "hello" \
  --greedy \
  --output tests/data/bark/hello-greedy.json
```

For sampled fixtures, compare exact fixed-seed token/code outputs first. If
Torch and Rust RNG behavior cannot be made identical, keep the fixture useful by
checking first-step logits, valid-token masks, top-k/top-p distributions,
codebook layout, waveform shape, and bounded waveform statistics instead of
claiming exact sampled token parity.

Large full-output fixtures and model weights should stay local-only.
